# MagicDisc 1.0.1 验证记录

平台：Apple Silicon macOS。

## 已通过的功能验证

- 图片：PNG → BMP/WebP/PDF、PNG/GIF 压缩。
- 动图与视频：序列图 → GIF/APNG；GIF ↔ MP4、GIF → APNG、MP4 → APNG/MOV、MOV → GIF。
- PDF 合并页数、Apple Vision OCR 输出文本。
- AI：真实 RealESRGAN General x4 v3 推理，64×64 输入分别生成 128×128、192×192、256×256。
- 升级：保留用户轮盘顺序；满 12 项不覆盖；AI 预设只补充一次。
- 安装器：固定 SHA-256 原件校验、错误校验拒绝、取消、解压执行权限与引擎发现。

## 发布与界面

- 版本源为 Directory.Build.props，应用与 DMG 使用 1.0.1。
- 当前资源使用用户提供的 PNG 图标，生成多尺寸 ICO 和 macOS ICNS；侧栏顶部不再显示图标。
- 九个模型的中英用途说明已核对。
- 当前版本需通过 Release 发布、发布标记检查与 codesign 严格检查。
